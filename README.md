# Fieldkit website

Support page and privacy policy for the Fieldkit iOS app, published with GitHub Pages.

- Landing page: https://gpluta.github.io/fieldkit-app/home.html (the App Store **Marketing URL**; hero image `img/hero.jpg` = `swift Tools/make-header.swift <file>.png 2400 1100 scene`, saved as JPEG)
- Support: https://gpluta.github.io/fieldkit-app/ (the App Store **Support URL**: keep it at the root)
- Privacy policy: https://gpluta.github.io/fieldkit-app/privacy.html
- Features: https://gpluta.github.io/fieldkit-app/features.html (every tool, with screenshots in `img/`: 1000 px tall JPEG copies of `AppStore/screenshots/`)

Live since 2026-10-28 from the public repo `gpluta/fieldkit-app` (GitHub Pages, `main` branch, root). To update: edit the files here, copy them into that repo, commit and push.

**Don't rename or move `index.html` (Support) or `privacy.html`:** their addresses are entered in App Store Connect. The landing page lives at `home.html` for that reason.
